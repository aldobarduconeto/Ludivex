# Ícone atual — GameHub 3D

Arquivo mestre aplicado: `app_icon.png`. Original: `app_icon-v4.png`.

Controle 3D verde vibrante, iluminação azul, etiqueta de promoção com símbolo branco e fundo preto. Arte gerada com a ferramenta integrada image_gen.

Os ícones Android, iOS, Web, Windows e macOS são gerados por `flutter_launcher_icons` (restrição `^0.14.3`). Linux reutiliza `web/icons/Icon-512.png` no instalador e na janela.

Para regenerar: `dart run flutter_launcher_icons`.
